02 · 사용할 에이전트

로그인은 각 공식 CLI에서 직접 진행합니다. AGENT HUB는 계정 비밀번호를 받지 않습니다.

03 · Coral 연결 정보

허브와 자동 작업자는 서로 다른 신원을 사용합니다. 선택한 에이전트와 허브 신원은 Coral 세션에 미리 등록되어 있어야 합니다.

파일 형식: 이름|MCP_URL. 파일을 매번 다시 읽어 주소 교체를 따라갑니다. 파일이 없다면 아래에 각 MCP URL을 입력하세요.

별도 작업 세션에서 읽기·분석·답변을 수행합니다. 계정 사용량을 소비하며 기존 IDE 대화를 이어받지 않습니다. 동일 신원을 처리하는 다른 실행기는 먼저 중지하세요.

추가 수신 호출 없이 진행 중인 Claude의 읽기 도구 완료 시 메시지를 전달합니다. 수신이 확인되지 않으면 다음 과제로 전달합니다. Cursor는 기존 묶음 전달을 사용합니다.

HUB 훅 신뢰 등록 후 적용됩니다. 미등록·코드 변경·수신 미확인 시 기존 다음 과제 전달을 유지합니다. 설치 안내의 Codex 훅 등록 명령을 먼저 실행하세요.

ROLE WORKFLOW

의견을 결과물로

계획 → 구현 → 테스트·검토 순서로 진행합니다.

새 작업은 커밋된 저장소를 복제하고, 후속 작업은 선택한 사본의 현재 결과를 이어 씁니다. 에이전트는 직접 게시하지 않습니다. 완료 후 원본 반영 화면에서 커밋·push를 별도로 선택할 수 있습니다.

검증 명령 찾기

비워 두면 테스트 실행 없이 담당 에이전트가 결과물을 검토합니다. 입력하면 Hub가 작업 사본에서 직접 실행하며 도구와 의존성이 필요합니다. 명령 한 개만 지원하며, 검증 중 소스 파일을 수정하면 보류합니다.
