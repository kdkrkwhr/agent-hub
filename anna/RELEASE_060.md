# Agent Hub Radio 0.6.0

2026-10-15 소유자 테스트 배포. 공개 출시와 심사 제출은 하지 않았다. 설계는 [docs/superpowers/specs/2026-10-15-anna-office-design.md](../docs/superpowers/specs/2026-10-15-anna-office-design.md).

## 바뀐 점

- 채널 제목 아래 `대화 | 사무실` 탭. 사무실은 원래 Agent Hub의 사무실 화면을 SVG로 옮긴 지도다.
- 업무 사무실: 휴게실·연구실(의견)·토론실(반박)·조율실(최종안)·검토실(검토). 역할은 지금 하는 단계의 방으로 복도를 따라 걸어가고, 작성 중인 역할 위에 말풍선이 뜬다. 요청이 끝나면 모두 휴게실로 돌아온다.
- 투표실: 역할마다 칸막이 부스. 모든 표가 모이기 전에는 "판단 중"/"제출함"만 보이고, 공개되면 고른 선택지 구역(A~F)이나 "기권·무효" 구역으로 걸어간다.
- 캐릭터를 누르면 단계·상태·실제 모델·최근 발언 카드와 `대화에서 보기` 버튼이 나온다. 투표 공개 전에는 표 내용을 숨긴다.
- 역할 상태 칩(대기·작성 중·완료·실패 등)이 지도 위에 표시된다.
- `prefers-reduced-motion`이면 걷지 않고 바로 옮긴다. 좁은 창(560px 이하)에서는 카드가 지도 아래로 간다.
- 미니맵, 확대·축소, 카메라 따라가기, 떠 있는 팀 대화창, 전체화면은 넣지 않았다.

## 남은 제한

- 실제 AI 호출로 사무실이 움직이는 모습은 확인하지 않았다(Anna AI 사용량 소진). 진행 중 이동과 말풍선은 목 SDK 브라우저 테스트로만 확인했다.

- 이전 제한(`llm.stream` 권한 없음, 중지 시 서버 요청 취소 안 될 수 있음, 발언 8000자 제한, 창 안 MD 내려받기 미확인)은 그대로다.
