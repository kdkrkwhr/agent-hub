# 0.7.1 검증 기록 — 2026-10-22

사용자 3~5명의 제품 가치 검증은 사용자의 요청에 따라 이번 범위에서 제외했다. 저장 안정성과 실제 Anna 실행 검증이 이번 작업 범위다.

## 실제 Anna 저장소

앱 소유자용 공식 developer storage token으로 현재 앱의 임시 검증 prefix 아래에서 테스트했다. 기존 사용자 데이터는 수정하지 않았고 검증 데이터만 정리했다. 근거 JSON은 Git 제외 경로 `runtime/review-plan/live-storage-071.json`에 있다.

| 검증 | 결과 |
|---|---|
| 동일 ETag로 동시 수정 | 1건 성공, 1건 HTTP 412 `precondition_failed` |
| 오래된 ETag 수정·삭제 및 삭제 후 재저장 | 최신 값 보존, 조건부 요청 거부 |
| 본문+목록 metadata | 원자적 저장 및 목록 조회 확인 |
| 크기 경계 | UTF-8 JSON 262,144 bytes 성공, 524,288 bytes HTTP 413 `value_too_large` |
| 긴 한국어 심층 기록 | 요청 4,000자 + 응답 8,000자 × 9개, 총 229,158 bytes 저장·재조회 성공 |
| 서로 다른 최초 기록·채널 동시 생성 | 모두 목록에 남음 |
| 최초 설정 동시 수정 | 언어 변경과 서로 다른 관찰 모델 모두 보존 |

공식 저장 참조: [Anna Host Storage API](https://raw.githubusercontent.com/Anna-Partners/anna-developer-docs/main/reference-data/shards/reference-host-api-storage.json). 현재 사용한 API는 기본 app/self 범위이며 cross-user·cross-app 권한을 요청하지 않는다.

## 자동 검증

단위 테스트는 기존 기능에 더해 두 store 인스턴스 간 충돌, 최초 저장 경합, 삭제 후 부활 방지, 진행 중인 실행 소유권, 1,500개 기록 페이지 조회, 한국어 크기 경계를 확인한다. 브라우저 테스트는 모의 SDK/AI를 사용한다. 충돌 시 답변 보존·최신 기록 불러오기, 진행 중인 기록 열람의 무변경, 용량 오류 후 저장만 재시도, 불완전한 내보내기 차단을 포함한다.

최종 **단위 95개 / 브라우저 51개 / strict manifest validation 통과**. 기존 인덱스에 생성 시각이 없는 테스트의 표시 순서 2건은 본문 생성 시각 기준으로 기대값을 수정한 후 전체 재검증했다. 브라우저 테스트는 한국어·영어 및 360px 레이아웃을 포함한다.

## 실제 설치 확인

배포 및 실제 AI 확인 진행 중. 아직 설치 완료를 의미하지 않는다.

## 검증의 한계

- 두 번째 로그인 계정이 없어 실제 두 계정 간 데이터 격리는 미확인이다. 저장 권한은 공식 app/self 기본 범위이며 자동 테스트를 실제 다중 계정 검증이라고 주장하지 않는다.
- 실제 계정 할당량을 고의로 소진하지 않는다. quota 및 저장 장애 분기는 모의 테스트로 확인한다.
- 같은 계정의 동시 요청과 실제 조건부 저장은 검증하지만 물리적으로 다른 두 기기를 직접 사용한 테스트는 아니다.
- 150초 실행 소유권과 응답 저장으로 중복 실행을 줄인다. 타임아웃·창 종료 당시 이미 시작한 서버 생성이 취소됐는지, 재시도에 중복 과금이 없는지는 보장하지 않는다.
- 구버전 창은 ETag 없이 저장할 수 있다. 모든 창을 최신 설치본으로 다시 열어야 한다. 새 형식의 설정·새 채널은 구버전 화면에서 보이지 않을 수 있으므로 0.7.1 저장 이후 임의 다운그레이드하지 않는다.
- 설정 변경 기록은 보존되며 페이지 단위로 읽는다. 계정 저장량을 무제한으로 보장하지 않는다. UI는 최근 30건, Markdown 내보내기는 전체 기록을 대상으로 한다.
