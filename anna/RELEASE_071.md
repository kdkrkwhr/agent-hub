# Agent Hub Radio 0.7.1

출시 준비를 위한 저장 안정성과 실행 복구 보강. 소유자 테스트 draft이며 1.0 심사 후보는 생성하지 않는다.

- 기록 본문과 목록용 요약을 한 번에 저장한다. 거대한 공용 인덱스 대신 개별 기록 목록을 페이지 단위로 조회한다. 기존 본문·채널·설정은 호환해서 읽고 보존한다.
- 기록 수정·삭제는 Anna ETag 조건부 요청을 사용한다. 오래된 화면의 저장이 최신 기록을 덮거나 삭제한 기록을 되살리지 못하게 한다.
- 새 채널은 독립된 키에 저장한다. 기존 채널 배열의 수정은 조건부 갱신으로 처리하며 다른 채널의 변경은 병합한다.
- 설정은 변경된 필드와 새로 관찰한 모델만 별도 기록으로 저장한다. 최초 동시 접속에서도 언어·역할·관찰 모델 변경이 서로 지워지지 않는다. 같은 설정 필드의 동시 변경은 서버 저장 순서로 결정되며 실시간 공동 편집을 제공하지 않는다.
- 토론 실행 전 최대 150초 동안 진행 소유권을 기록한다. 다른 창에서 진행 중인 토론을 열어도 중단 상태를 서버에 덮어쓰지 않으며, 중복 AI 시작을 막는다. 연결 종료 후에는 사용자가 최신 기록을 읽고 재개한다.
- 충돌·저장 공간/크기·권한·연결 문제를 구분해 안내한다. 받은 답변은 화면에 남기며 복사와 저장만 재시도를 지원한다. 충돌 시 강제 덮어쓰기 대신 최신 기록 불러오기를 제공한다.
- 기록 새로고침 버튼을 추가한다. 내보내기 중 읽기 실패가 있으면 일부 기록만 담은 파일을 다운로드하지 않는다.
- 최신 기록을 다시 불러오면 이전 저장 충돌·진행 중 경고를 해제하고 성공 안내를 표시한다.
- 기존 인덱스에 생성 시간이 빠져 있던 기록도 본문의 실제 생성 시간 순서로 표시한다.

실제 APS에서 256 KiB/행 제한, UTF-8 JSON 크기, ETag 및 목록 메타데이터를 확인했다. 앱은 248 KiB에서 설명과 함께 저장을 멈추며 내용을 조용히 삭제하지 않는다. 최대 길이 한국어 요청과 9개 응답(테스트 데이터 229,158 bytes)은 실제 저장·재조회에 성공했다. 누적 저장량은 Anna 계정 할당량의 영향을 받는다.

오래 열린 구버전 창은 업데이트 후 다시 열어야 한다. 연결 종료 당시 서버 생성 취소와 정확히 한 번 과금은 보장하지 않는다. 자세한 검증 범위와 배포 상태는 [VALIDATION_071.md](VALIDATION_071.md), [HANDOFF.md](HANDOFF.md)에 기록한다.

최종 배포: 코드 `c41bd7a`, working revision **7**, 소유자 설치 화면 **v0.7.1** 확인. 단위 95개·브라우저 51개 통과 후 경고 해제 수정 관련 7개를 추가 재검증했다. 실제 심층 토론 9개 응답 완료, 중단·복원·재개와 두 창의 실행 충돌, 모델 가용성 오류를 확인했다. 별도 계정 격리와 외부 사용자 평가는 남아 있으며, 심사는 제출하지 않았다.

2026-10-22 소개 자료 보완: 한·영 사용자 안내·데이터 처리 안내와 심사자 재현 문서를 추가하고, 실제 설치 화면 4장을 README와 Anna 등록정보에 반영했다. 기본 심사 경로의 빠른 검토 4회+투표 3회 사용량을 안내한다. 소개 자료 커밋 `8969f22`, strict validation과 내부 링크 42개 검사, 서버 등록정보 일치·공개 링크 및 이미지 HTTP 200을 확인했다. 이 작업에는 UI 변경이나 새 AI 호출이 없으며, 버전·working revision·번들 hash를 유지했다. 1.0 후보 생성·심사 제출은 별도 단계다.
