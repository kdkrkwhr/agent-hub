# Agent Hub Radio 0.8.0

영어를 기본으로, 한국어·중국어(간체)·일본어까지 선택할 수 있게 했다. 첫 심사 목표는 1.0.0이며 이번 버전은 소유자 테스트 draft다.

- 새 사용자와 알 수 없는 언어 설정의 기본값은 영어다. 저장된 유효한 언어 선택은 유지한다.
- 모델 설정에서 **English / 한국어 / 简体中文 / 日本語**를 고른다. 메뉴, 상태, 오류·저장 복구 안내, 첫 사용 예시, 역할 설명, 사무실 표기, 날짜와 Markdown 내보내기에 반영한다.
- 새 토론·투표는 선택한 언어로 답하도록 요청한다. 결정 요약의 다섯 제목도 각 언어로 처리한다. 투표 JSON의 필드 이름과 선택지 ID는 고정하고 근거·우려만 선택 언어로 생성한다.
- 언어를 바꿔도 입력 초안과 기존 답변을 바꾸지 않는다. 진행 중·중단된 요청은 시작할 때 저장된 언어로 계속한다. 언어 값이 없던 오래된 기록은 이전 한국어 동작을 유지한다.
- 언어 전환이나 재접속만으로 AI를 호출하지 않는다. 설정 창에서 전환 범위를 설명한다. 설정을 저장하지 못하면 이전 언어로 돌아온다.
- 기본 HTML도 영어로 바꿔 초기 연결·로딩 단계가 새 기본값과 일치하게 했다.

자동 검증과 실제 설치 결과, 배포 revision과 hash는 [HANDOFF.md](HANDOFF.md)에 기록한다. 실제 번역 문구는 구현·화면 검증 범위이며 원어민 사용자 평가는 아직 수행하지 않았다. 기존 0.7.1 스토어 캡처는 촬영 버전을 명시한 채 유지하고, 최종 1.0 제출 전에 소개 자료를 다시 대조한다.

2026-10-23 검증·배포 완료: 단위 **101개**, 브라우저 **58개**, strict validation 및 Windows·Linux Anna CI 통과. 소유자 설치본은 **0.8.0 / revision 8 / bundle ready**다. 실제 네 언어 전환·기존 응답과 초안 보존·재접속을 확인했고, 기존 데이터와 모델 설정을 유지했다. 이번 검증의 새 AI 호출은 없다. [검증 근거와 제한](VALIDATION_080.md).
