# Agent Hub Radio 0.5.0

2026-10-15 소유자 테스트 배포. 공개 출시와 심사 제출은 하지 않았다. 설계는 [docs/superpowers/specs/2026-10-15-anna-ui-redesign-design.md](../docs/superpowers/specs/2026-10-15-anna-ui-redesign-design.md).

## 바뀐 점

- 원래 Agent Hub처럼 어두운 남색·민트 테마로 화면 전체를 다시 만들었다.
- 채널 사이드바: 새 채널, 채널 전환, 이름 변경, 닫기·다시 열기, 닫힌 채널 표시, 채널 전체 Markdown 저장. 좁은 화면(760px 미만)에서는 ☰ 서랍으로 열린다.
- 요청마다 독립된 토론이고, 채널은 요청을 묶기만 한다. 0.4.x 기록은 "이전 기록" 채널에 모인다.
- 대화는 말풍선 타임라인으로 보인다. 역할별 아바타·색, 단계, 실제 모델 배지, 진행 중 표시, 중지·이어하기·건너뛰기·다시 시도·복사·삭제.
- 입력창: @역할 칩, Enter 전송(Shift+Enter 줄바꿈, 한글 조합 중에는 보내지 않음), 예상 AI 호출 수.
- 독립 비밀 투표는 별도 창에서 지문·선택지(2~6개)·투표 역할을 정하고, 결과는 막대로 공개한다.
- 모델 설정과 언어는 설정 창으로 옮겼다.

## 검증

- 단위 테스트 71/71, 브라우저 테스트 36/36(목 SDK, CSP 헤더), `anna-app validate --strict` 통과.
- GitHub Actions: Tests 38689136407, Anna app 38689136302 성공.
- 설치된 실제 화면(anna.partners 대시보드, AI 호출 없이):
  - 어두운 배경(`rgb(12, 16, 23)`)과 사이드바 버전 `v0.5.0` 표시.
  - 새 채널 생성 → 역할 칩 3개 선택됨, "AI 호출 9회 예정".
  - 이름 변경 창으로 "설치 확인 0.5.0"으로 변경.
  - 투표 창 열기(선택지 2개) → 취소로 닫힘. 설정 창 열기 → 닫기.
  - 채널 닫기 → 입력창 잠김과 안내 문구, 다시 열기 → 풀림, 다시 닫기 확인.
  - 확인용 채널 "설치 확인 0.5.0"은 닫힌 상태로 남아 있다(기록 0건). 이전 기록이 없어 "이전 기록" 채널은 나타나지 않았다.

## 남은 제한

- 실제 AI 호출은 검증하지 않았다(Anna AI 사용량 소진). 실제 스트림 동작, 모델 이름 표시, 할당량 오류 문구는 사용량이 회복되면 확인해야 한다.
- `llm.stream`이 권한 목록에 없다. 거부되면 `llm.complete`로 대체되며 글자가 한 번에 표시된다.
- 중지를 눌러도 이미 보낸 서버 쪽 요청은 취소되지 않을 수 있다.
- 발언은 8000자에서 자른다.
- Anna 창 안에서의 Markdown 파일 내려받기는 확인하지 않았다(복사 대체 경로 있음).
- 사무실·투표실 지도 화면은 0.6.0에서 만든다.
