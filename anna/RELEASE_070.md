# 0.7.0 — 다음 출시의 기능 우선순위 검토

0.x 소유자 테스트용 변경이다. 첫 심사 목표는 1.0.0이며 이번 변경으로 심사 제출이나 공개 출시를 하지 않는다.

- 기본 흐름을 **기능 우선순위 · 빠른 검토**로 변경했다. 3역할이면 독립 의견 3회와 정리 1회다. 기존 심층 토론 9회와 독립 투표는 유지했다.
- 최종안을 먼저 만들기, 미루기, 판단 근거, 확인할 가정, 다음 행동으로 표시한다. 원문 의견을 펼치거나 결정 요약을 복사할 수 있다. 형식이 맞지 않으면 원문을 손실 없이 표시한다.
- 입력 예시, 예상 호출 횟수, 사용자 Anna AI 사용량과 요청별 문맥 안내를 추가했다.
- 저장이 실패하면 후속 AI 호출을 멈춘다. 받은 답변을 유지하고 **저장만 다시 시도**로 복구하며, 이 버튼은 AI를 호출하지 않는다.
- 빈 응답과 출력 제한·필터링 등의 중간 종료를 완료로 취급하지 않는다. 자동 유료 재시도를 추가하지 않았다.
- Anna 사용자 안내와 실제 기능에 맞는 앱 설명을 작성했다. 미구현 문서 파이프라인 표현을 제거했다.

검증: 단위 86개, 브라우저 47개 시나리오, strict validation. 실제 Anna API에서 빠른 검토·투표를 완료했고 단일 응답과 비교했다. 세부 결과와 제품 가치의 미확인 부분은 [검증 기록](VALIDATION_070.md)을 참고한다.

남은 제한: 역할이 같은 모델을 사용할 수 있으며 합의는 정확성 검증이 아니다. 기존 채널 문맥을 자동으로 연결하지 않는다. 여러 기기 충돌·대량 기록 경계·별도 계정 첫 사용과 실제 사용자 재사용 가치는 1.0 전 추가 검증이 필요하다. 미저장 답변은 창을 닫기 전에 복사하거나 저장을 복구해야 한다.

배포: working revision **5**, `0.0.0-draft` 소유자 설치 UI **v0.7.0** 확인. 실제 빠른 검토·투표·복사·Markdown 다운로드·창 재열기 후 복원을 검증했다. 최신 cut 0.6.0은 유지하며, 앱은 미공개·미제출 상태다. 상세 해시와 설치 검증은 [인수인계](HANDOFF.md)에 기록했다.
