# Agent Hub Radio · 스토어 소개 원고

2026-10-22 · 소개 원고 0.8.0 기준, 이미지는 0.7.1 실제 설치 화면. 첫 심사 목표 1.0.0이며 아직 제출하지 않았다. 현재 배포 상태는 [인수인계](../HANDOFF.md)를 확인한다.

스토어에 동기화하는 영문 원문과 이미지 순서는 [`../app.json`](../app.json)이 기준이다. 아래 한국어는 국내 소개에 사용할 수 있다. 사용자 안내: [한국어](../README.md) / [English](../README.en.md), [데이터 처리](../DATA_USE.md).

## 한국어 짧은 소개

다음 출시, 무엇부터 만들까요? 분석가·비판자·정리자와 기능 우선순위를 정리하는 AI 회의실입니다.

## 한국어 상세 소개

만들고 싶은 기능은 많은데, 이번 출시에는 무엇부터 넣어야 할지 고민되나요?

Agent Hub Radio에 대상 사용자, 출시 목표, 개발 여력과 후보 기능을 알려 주세요. 분석가·비판자·정리자가 각자의 관점에서 살펴보고, **먼저 만들 것과 미룰 것, 판단 근거, 확인할 가정과 다음 행동**을 정리해 줍니다. 예시를 채운 뒤 내 프로젝트에 맞게 고쳐 시작할 수 있어요.

- **빠른 검토:** 역할별 의견과 결정 요약을 확인합니다.
- **심층 토론:** 반박과 최종안 이후의 동료 검토까지 읽으며 남은 이견을 살펴봅니다.
- **독립 비밀 투표:** 2~6개 선택지를 비교하고, 모든 역할의 처리가 끝난 뒤 표와 근거를 확인합니다.
- **채널과 기록:** 주제별로 모아 두고 다시 열거나 요약을 복사하고 Markdown으로 내보냅니다.
- **사무실:** 역할들의 작업 상태를 한눈에 확인합니다.
- **네 가지 언어:** 기본은 영어이며 한국어·중국어(간체)·일본어를 선택할 수 있습니다. 화면과 새 AI 요청에 적용하고 기존 기록은 원문으로 보존합니다.

Anna 안에서 별도 CLI·API 키·개발자 서버 없이 실행합니다. **내 Anna 계정의 AI 사용량을 사용**하며, 세 역할 기준 빠른 검토는 4회, 심층 토론은 9회, 투표는 3회 호출합니다. 재시도에는 추가 사용량이 발생할 수 있고 호출 수는 토큰 수나 요금과 같지 않습니다.

각 요청은 별도 검토이며 이전 대화가 자동으로 이어지지는 않습니다. 세 역할이 같은 모델을 사용할 수 있고, 모델 설정은 선호 조건입니다. 실제 모델 이름은 응답에서 확인할 수 있습니다. AI의 의견 일치나 다수결은 사실 확인이 아니므로, 제안을 읽고 최종 판단을 내려 주세요. 코드 실행이나 파일 수정 기능은 제공하지 않습니다.

## 소개에서 약속하지 않는 기능

현재는 로컬 Claude Code·Codex·Cursor 프로세스 연결, 코드 실행·파일 수정, 문서 작성 파이프라인, 자동 채널 문맥 연결, 팀 공유, Android/iOS 지원을 제공한다고 소개하지 않는다. 세 역할이 서로 다른 모델이라는 보장이나 단일 AI보다 정확하다는 주장도 하지 않는다.
