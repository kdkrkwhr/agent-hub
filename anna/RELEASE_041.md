## 바뀐 점

0.4.0(2단계)
- 역할 토론: 역할별 의견 → 서로 반박 → 정리자 최종안 → 나머지 역할 검토. 3명이면 AI 호출 9회.
- 독립 투표: 역할이 다른 표를 보지 않고 고르고, 모든 표가 모이면 결과를 공개한다.
- 기록: 진행 중 중지·이어하기, 발언 건너뛰기, 보관, 삭제(두 번 눌러 확인).
- Markdown 내보내기와 복사. 발언마다 요청한 모델과 실제 사용된 모델을 함께 적는다.

0.4.1
- 스트림 호출이 권한 오류(`permission_denied`, `forbidden`)로 거부되면 글자가 오기 전에 한해 `llm.complete`로 다시 요청한다. 배포된 번들 권한 목록에 `llm.stream`이 따로 없어서 넣은 안전장치다.

## 남은 제한

- 실제 AI 호출은 검증하지 않았다(Anna AI 사용량 소진). 실제 스트림 동작, 모델 이름 표시, 할당량 오류 문구는 사용량이 회복되면 확인해야 한다.
- `llm.stream`이 권한 목록에 없다. 거부되면 0.4.1부터 `llm.complete`로 대체되지만, 그 경우 글자가 흘러나오지 않고 한 번에 표시된다.
- 중지를 눌러도 이미 보낸 서버 쪽 `llm.complete` 요청은 취소되지 않을 수 있다.
- 발언은 8000자에서 자른다. 저장 분할은 하지 않는다.
- Anna 창 안에서의 Markdown 파일 내려받기는 확인하지 않았다(복사는 대체 경로 있음).
- 설치된 화면의 CSP 콘솔 오류는 iframe 콘솔에 접근할 수 없어 직접 확인하지 못했다. 화면이 정상 동작하고 브라우저 테스트가 같은 CSP로 통과한 것으로 갈음했다.
- 문서 파이프라인과 오피스 화면은 3단계에서 만든다.
