# 공통 컨텍스트를 사용하는 CLI 세션

한 터미널에서 `@claude`, `@codex`, `@cursor`로 다음 턴의 담당자를 선택합니다. 대화 원문과 실행 결과는 Hub SQLite에 저장하고, 세 에이전트는 세션의 같은 Git 작업 사본을 순서대로 사용합니다. 원본 저장소는 수정하지 않습니다.

## 시작과 재접속

Python 패키지를 설치한 뒤 로그인된 네이티브 CLI를 준비하세요. 수동 세션은 Coral 연결이나 **허브 자동 응답** 설정과 관계없이 사용자의 입력으로 실행됩니다. 실제 CLI 호출에는 해당 서비스 사용량이 발생합니다.

```powershell
agent-hub chat --source D:\projects\my-app --agent claude
```

소스 체크아웃 상태에서는 다음과 같이 실행합니다.

```powershell
$env:PYTHONPATH = 'src'
python -m agent_hub chat --source D:\projects\my-app
```

`--source`를 생략하면 현재 폴더를 사용합니다. 시작 대상은 커밋이 있고 미커밋·미추적 파일, 심볼릭 링크, 서브모듈이 없는 Git 저장소여야 합니다. 시작할 때 별도 사본을 만들고 화면에 **실제 작업 사본 경로**를 표시합니다. 편집기에서도 그 사본을 열면 수정 결과를 볼 수 있습니다.

같은 로컬 포트에 Hub가 실행 중이면 연결합니다. 실행 중인 Hub가 없으면 CLI 프로세스 안에서 **수동 세션만 실행하는 서버**를 시작하며, CLI 종료 시 그 서버도 종료됩니다. 이 경로는 저장된 자동 응답 설정을 변경하지 않고 기존 자동 작업이나 Coral 서버를 시작하지 않습니다. Coral 동기화와 웹의 자동 작업을 함께 사용하려면 일반 Hub를 먼저 실행한 뒤 CLI로 연결하세요. 이미 실행 중인 서버에 연결한 경우에는 서버를 종료하지 않습니다. `--data-dir`, `--port`로 저장소와 포트를 선택하거나 `--server http://127.0.0.1:8768`로 실행 중인 서버만 지정할 수 있습니다.

```text
claude> @claude 회원가입 API 스켈레톤을 작성해줘.
claude> @codex 방금 @claude가 작성한 코드의 보안 문제를 검토해줘.
codex> @cursor 검토에서 지적된 부분을 수정해줘.
cursor> /check python -m unittest discover -s tests -v
cursor> @claude 방금 검증 결과를 확인하고 필요한 수정을 해줘.
cursor> /export
cursor> /exit
```

앞의 `@cursor`만 담당자를 지정하며 본문에 등장하는 `@claude`는 참고 표현입니다. 멘션만 입력하면 호출 없이 담당자를 바꾸고, 멘션 없는 입력은 현재 담당자에게 전달합니다. 한 세션에서는 한 턴만 실행합니다. 동일 원본 프로젝트의 다른 수동 실행·역할 작업·원본 반영과도 실행이 겹치지 않도록 검사합니다.

시작할 때 출력된 재접속 명령에는 세션 ID와 데이터 폴더·포트가 포함됩니다. 사용자 지정 데이터 폴더를 사용했다면 재접속에도 같은 옵션을 사용하세요. 중단된 서버의 턴은 자동으로 재실행하지 않습니다.

```powershell
agent-hub chat --list
agent-hub chat --resume manual-세션ID
agent-hub chat --source D:\projects\my-app --read-only
```

`--resume`은 저장된 작업 폴더, 담당자, 권한을 유지합니다. 이미 진행 중인 턴은 새 호출 없이 그 출력을 다시 보여 줍니다. CLI 통신 실패 시 요청을 자동 재전송하지 않으며 `/status` 또는 재접속으로 실행 여부를 확인할 수 있습니다. 요청 ID가 같은 제출은 한 번만 등록됩니다.

## 공통 컨텍스트

각 턴은 공통 지침과 다음 정보를 하나의 패킷으로 받습니다.

- 세션 ID, 상태 버전, 공통 컨텍스트 해시, 최신 사용자 요청
- 사용자 지정 공통 요약과 그 이후의 대화·실행 결과
- 작업 사본 경로, 시작 커밋, 현재 파일 지문
- 변경 파일과 명시적으로 포함한 파일의 UTF-8 본문, Git diff, 새 파일·삭제 파일·바이너리 정보
- 이전 호출의 도구 이벤트, 검증 명령·종료 코드·출력, 실패·취소 상태

담당자에 따라 공통 패킷을 요약하거나 변경하지 않습니다. 각 CLI는 새 호출로 시작하며 이전 네이티브 세션을 resume하지 않습니다. CLI별 시스템 지침·프로젝트 규칙·도구 설정이나 모델 내부 추론까지 동일하게 만드는 기능은 아닙니다. 실제 작업 상태는 파일과 실행 결과를 기준으로 확인합니다.

기본 입력 한도는 공통 패킷 **UTF-8 192KB**, 파일 본문은 각각 **64KB**입니다. 모델별 토큰 한도를 보장하는 값은 아니며, 초과하면 호출 전에 오류를 표시합니다. 대화나 diff를 조용히 자르지 않습니다.

`/compact 요약`은 이전 대화 대신 전달할 요약을 사용자가 지정합니다. 반드시 유지할 조건·결정·남은 작업을 포함하세요. 이후 모든 에이전트가 같은 요약을 사용하며, 이전 대화 원문은 `/history`에서 계속 확인할 수 있습니다. 별도 요약 모델 호출은 없습니다.

`/include src/auth.py`는 수정되지 않은 관련 파일도 패킷에 포함합니다. `/exclude 큰파일`은 해당 파일의 본문과 diff를 패킷에서 제외하고 제외 경로를 명시합니다. 파일과 그 변경 자체는 사본·파일 지문·결과물에 유지되며 에이전트가 파일 도구로 읽을 수 있습니다. `.gitignore`로 제외된 파일은 자동 수집하지 않습니다.

## 중단, 검증, 결과물

실행 중 **Ctrl+C**를 누르면 프로세스 종료를 요청하고 종료 후 파일 상태를 기록합니다. 취소·실패 전에 만들어진 변경을 자동으로 되돌리지 않습니다. 서버 재시작으로 실행 상태를 잃었거나 외부에서 사본을 바꿨으면, 이전 CLI가 종료되었는지와 파일 변경을 확인한 뒤 `/sync`로 계속합니다. 외부 편집기에 대한 OS 수준의 파일 잠금은 제공하지 않습니다.

에이전트에는 파일 읽기·검색과 허용된 편집을 맡기고, 빌드·테스트는 `/check 명령`으로 호스트가 실행합니다. 명령의 종료 코드와 출력이 다음 에이전트의 컨텍스트에 들어갑니다. 셸 연결·리다이렉션과 Windows 배치 파일 직접 실행은 기존 역할 작업과 동일하게 제한됩니다. 검증 명령이 파일을 생성하거나 변경하면 그 변경도 다음 턴에 유지됩니다. `--read-only` 세션에서는 `/check`를 실행하지 않습니다.

호출의 `completed`는 CLI의 정상 종료를 뜻하며, 요구사항 충족이나 테스트 통과를 자동으로 선언하지 않습니다. CLI 도구 권한은 제공자별로 다르며 완전한 OS 격리를 보장하지 않습니다. Cursor의 편집 호출은 파일 반영을 위해 headless `--force`를 사용합니다.

`/export`는 `artifacts/<세션ID>/<상태버전>/`에 누적 패치·변경 파일 ZIP·보고서를 만듭니다. 원본 반영·커밋·push는 자동 실행하지 않습니다. `/close`는 세션을 종료하며 기록·사본·결과물을 보존합니다. 이후 기록 조회와 내보내기는 가능하지만 새 턴은 실행하지 않습니다. `/exit`는 세션을 종료하지 않고 CLI만 닫습니다.

## 기존 Coral 채널에 기록하기

Coral에 연결된 실행 중인 Hub에서 열린 채널 ID를 지정하면 각 완료·실패·취소 결과를 그 채널에도 전달합니다.

```powershell
agent-hub chat --source D:\projects\my-app --thread 기존채널ID
```

이 채널은 세션이 종료될 때까지 수동 모드로 취급합니다. 일반 채널 메시지나 답변 속 멘션이 토론·투표·역할 작업을 자동으로 시작하지 않습니다. 웹에서 입력한 일반 메시지는 채널 기록이며 CLI 실행 지시로 가져오지 않습니다. 에이전트 선택과 지시는 CLI에서 입력하세요.

동기화 메시지는 멘션 없이 보내며, 로컬 원문은 길이에 관계없이 보관합니다. Coral에 보내는 긴 메시지는 전체 기록의 위치를 표시한 발췌입니다. 연결 장애 시 로컬 작업을 보존하고 다음 동기화에서 전송 표식을 확인해 중복을 줄입니다. 연결 설정이 바뀌면 이전 채널에 보내지 않습니다.

## 개발 검증

`python -m unittest discover -s tests -p test_manual.py -v`는 모의 에이전트로 세 제공자 인계, 공통 컨텍스트, 실제 임시 파일 변경·검증 명령, 중단·재접속, 입력 한도, 경로 검사, HTTP CSRF를 확인합니다. 실제 로그인된 제공자에 대한 유료 호출은 별도 수동 검증 대상입니다.

2026-10-01 Windows 환경에서 Claude Code **2.1.283**, Codex CLI **0.157.1**, Cursor CLI **2026.09.28-64d2043**의 `--version`과 `--help`로 필요한 세션·출력 옵션을 확인했습니다. 이는 해당 버전의 실제 모델 호출이나 편집 성공을 검증했다는 뜻은 아닙니다. 프로세스 출력·종료 검증은 실제 Python 자식 프로세스로 만든 가짜 CLI를 사용합니다.
