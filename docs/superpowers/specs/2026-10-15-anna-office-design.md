# Agent Hub Radio 0.6.0 사무실·투표실 설계

2026-10-15, 사용자 승인. 0.5.0 화면 개편([2026-10-15-anna-ui-redesign-design.md](2026-10-15-anna-ui-redesign-design.md))의 2단계.

## 목표

원래 Agent Hub의 사무실 화면(`src/agent_hub/static/office.js`)처럼, 역할들이 진행 단계에 따라 방을 옮겨 다니는 지도를 Anna 앱에 넣는다. 범위는 "핵심만"이다.

포함: 업무 사무실·투표실 지도, 단계별 방으로 걸어가는 캐릭터, 말풍선, 캐릭터를 누르면 나오는 최근 발언 카드, 역할 상태 줄.
제외: 미니맵, 확대·축소·드래그, 카메라 따라가기, 떠 있는 팀 대화창, 전체화면.

## 화면

- 채널 제목 아래 탭 `대화 | 사무실`. 사무실 안에 `업무 사무실 | 투표실` 전환.
- 보여 주는 요청: 이 채널에서 진행 중인 요청, 없으면 가장 최근 요청. 그 요청이 투표면 사무실 탭을 열 때 투표실을 먼저 보여 준다. 요청이 없으면 모두 휴게실에 있다.
- 채널이 없으면 탭을 숨긴다. 채널을 바꾸면 대화 탭으로 돌아가지 않고 현재 탭을 유지한다.

## 업무 사무실

| 방 | id | 있는 때 |
| --- | --- | --- |
| 휴게실 | `lounge` | 차례 전, 끝난 뒤, 건너뜀, 중지 |
| 연구실 | `research` | 의견(`opinion`) |
| 토론실 | `forum` | 반박(`rebuttal`) |
| 조율실 | `synthesis` | 최종안(`final`) |
| 검토실 | `review` | 검토(`review`) |

- 역할 위치: 진행 중인 차례가 있으면 그 차례의 방. 없으면 마지막으로 끝난(`done`/`failed`) 차례의 방. 요청이 끝났으면(`done`) 모두 휴게실. 아무 차례도 없으면 휴게실.
- 상태 라벨: 대기 · 작성 중 · 완료 · 실패 · 중지 · 건너뜀.
- 말풍선: 작성 중인 역할 위에 발언 앞부분 두 줄(최대 32자, 글자가 없으면 "작성 중…"). 지도 밖으로 나가지 않게 옆으로 민다.
- 역할 상태 칩은 방 전환·제목과 같은 줄에 둔다(Anna 창 높이가 낮아 지도를 최대한 크게 보이기 위해).
- 캐릭터는 역할 색 원형 아바타(AN/CR/ED)와 이름. 방을 옮기면 복도를 따라 걷는다. `prefers-reduced-motion`이면 바로 옮긴다.

## 투표실

- 투표 참여 역할마다 칸막이 부스. 모든 표가 모이기 전에는 부스에서 "판단 중"/"제출함"으로만 보이고 선택은 숨긴다.
- 공개 후(`tally` 결과가 있을 때) 각자 고른 선택지 구역(A~F)으로, 형식 오류·실패·건너뜀은 "기권·무효" 구역으로 걸어간다.
- 업무 요청을 보고 있을 때 투표실은 빈 방과 "이 채널의 최근 투표가 없어요"를 보여 준다. 투표실은 이 채널의 가장 최근 투표 요청을 보여 준다.

## 캐릭터 카드

캐릭터를 누르거나 Enter/Space로 고르면 지도 옆(좁은 화면에서는 아래)에 카드: 역할 이름, 단계, 상태, 실제 모델, 최근 발언 300자, `대화에서 보기` 버튼(대화 탭으로 바꾸고 해당 요청으로 스크롤). 투표 공개 전에는 표 내용을 보여 주지 않는다.

## 구조

- `office-model.mjs`: 순수 함수. `officeState(thread)` → `{room: 'office'|'vote', actors: [{role, zone, label, status, step, text, model, speaking}]}`. 투표는 `zone`이 `booth`, `option-A`…, `abstain`.
- `office-map.mjs`: 방·좌석 좌표(viewBox 기준), 복도 경로 계산 `route(from, to)`.
- `office-view.mjs`: SVG 그리기, `requestAnimationFrame` 이동, 카드, 탭 전환. 위치는 SVG `transform` 속성만 쓴다(인라인 style 없음, CSP 준수).
- `timeline-view.mjs`의 스트림 갱신(`onUpdate`)과 `render()`에서 사무실이 열려 있으면 `renderOffice(ctx)`를 부른다.

## 시험

- 단위: 단계별 방 배정, 끝난 요청은 휴게실, 투표 공개 전 부스·공개 후 선택지 구역·무효 구역, 경로가 복도를 지남.
- 브라우저(목 SDK, CSP): 탭 전환, 스트림 중 작성 역할이 해당 방에 있음, 투표 공개 후 구역, 카드와 `대화에서 보기`, 좁은 화면, CSP 위반 없음.
