# Agent Hub Radio 0.5.0 화면 개편

## 목표

Anna 앱의 겉모습과 사용 흐름을 원본 AGENT HUB RADIO처럼 바꾼다. 다크(남색·민트) 테마, 왼쪽 채널 사이드바, 역할별 말풍선 대화, 독립 비밀 투표 창. 사무실(업무 사무실·투표실 지도)은 0.6.0에서 따로 만든다.

토론·투표 엔진(`ai`, `runner`, `discussion`, `voting`, `roles`)과 기존 기록 형식은 바꾸지 않는다.

## 화면

- **사이드바**: 로고와 "AGENT HUB RADIO", `+ 새 채널`, 채널 목록(제목, 기록 수), `닫힌 채널 표시`, 아래쪽에 `모델 설정`과 버전. 760px보다 좁으면 사이드바는 드로어가 되고 상단 ☰ 버튼으로 연다.
- **상단 바**: 채널 제목, `모델 설정`, `이름 변경`, `MD 저장`, `채널 닫기`(닫힌 채널은 `다시 열기`).
- **대화**: 채널에 속한 토론·투표를 오래된 순서로 보여준다. 최근 30건까지.
  - 사용자의 요청은 오른쪽 말풍선.
  - 역할 발언은 왼쪽 말풍선. 분석가 청록 `AN`, 비판자 코랄 `CR`, 정리자 앰버 `ED`. 머리에 역할 이름, 단계, 실제 모델 배지(요청과 다르면 표시).
  - 대기 중인 발언은 숨기고, 진행 중인 발언은 글자가 흘러나오거나 "작성 중…"을 보인다.
  - 실패한 발언에는 오류 문구와 `다시 시도`, `이 역할 빼고 계속`(최종안 제외).
  - 기록마다 아래에 상태와 `중지`·`이어하기`·`복사`·`삭제`(두 번 눌러 확인).
- **입력창**: 역할 칩(@분석가 @비판자 @정리자, 누르면 켜고 끔), `자세히`, 예상 AI 호출 수, 요청 입력, `보내기`, `독립 비밀 투표`. Enter로 보내고 Shift+Enter로 줄바꿈한다. 한글 조합 중 Enter는 보내지 않는다. 안내 문구(`#notice`)는 입력창 아래 줄에 나온다.
- **투표 창**: "INDEPENDENT BALLOT · 같은 지문, 각자의 판단" 대화상자. 지문, 선택지 A~F(추가·삭제, 2~6개), 투표 참여 역할, `돌아가기`, `비밀 투표 시작`.
- **투표 카드**: 대화에 지문·선택지 말풍선과 투표 카드를 보인다. 모든 표가 모이기 전에는 역할별 "제출 완료"·"진행 중"만 보이고, 끝나면 역할별 선택·근거·우려와 선택지별 막대(`<progress>`)를 공개한다.
- **설정 창**: 역할·모델 설정과 언어를 대화상자로 연다. 저장 동작은 0.4.1과 같다.
- **빈 상태**: 채널이 없으면 안내와 `+ 새 채널`. 채널에 기록이 없으면 토론 흐름 안내.
- 닫힌 채널은 입력창을 막고 "다시 열면 이어서 쓸 수 있어요"를 보인다.

## 데이터

- 새 키 `channels`: `[{id, title, roles, archived, created, updated}]`. 제목은 60자, 역할은 알려진 역할만.
- 기록(`thread/<id>`)과 색인 항목에 `channel`을 더한다. 색인 항목에는 `created`도 더한다.
- `channel`이 없는 기존 기록은 가상 채널 `legacy`("이전 기록")에 보인다. 데이터는 옮기지 않는다. 이 채널의 이름을 바꾸거나 닫으면 그때 `legacy` 채널 기록이 생긴다.
- 채널 목록 정렬은 채널과 그 기록 중 가장 최근 시각 기준.
- 보내기 시 채널의 역할 선택을 저장한다.
- 채널 Markdown은 채널 제목 아래 기록별 Markdown을 `---`로 이어 붙인다. 파일명 `agent-hub-channel-<id>.md`.

## 모듈

- `channels.mjs`: 채널 생성·정리, 기록의 채널 판정, 채널 목록 계산(순수 함수).
- `store.mjs`: `listChannels`, `saveChannel` 추가, 요약에 `channel`·`created`.
- `export.mjs`: `channelMarkdown`, `channelExportName`.
- `shell-view.mjs`: 사이드바, 상단 바, 드로어, 채널 선택·이름 변경·닫기·내보내기.
- `timeline-view.mjs`: 기록·말풍선·투표 카드 그리기, 진행 중 글자 갱신, 실행과 기록별 동작.
- `composer-view.mjs`: 역할 칩, 예상 호출 수, 보내기.
- `ballot-view.mjs`: 투표 창.
- `settings-view.mjs`: 설정 창 열기·닫기 추가.
- `threads-view.mjs`, `compose-view.mjs`는 삭제한다.

CSP 때문에 인라인 스타일과 `element.style`은 쓰지 않는다. 막대는 `<progress>`, 상태는 클래스와 `data-*` 속성으로 표현한다.

## 테스트

- 단위: 채널 계산, 저장소의 채널 저장과 요약, 채널 Markdown.
- 브라우저(목 SDK): 채널 만들기·전환·닫기·이름 변경, 토론 9회와 실제 모델, 독립 의견, 모델 불일치 표시, 할당량 실패와 다시 시도, 중지 후 새로 고침과 이어하기, 투표 봉인과 공개, 투표 건너뛰기, 두 번 눌러도 1회 시작, 스트리밍 중 중지 버튼 유지, 입력 검증, 영어, 기존 기록의 `이전 기록` 채널, 복구, MD 저장, 복사 실패 대체, 삭제 두 번 확인, 설정 창 저장·언어·실패, 연결 실패, 360px 폭과 드로어, CSP 오류 없음.
