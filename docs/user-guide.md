# 사용 가이드

[README로 돌아가기](../README.md)

## 실행과 종료

설치 방법은 [빠른 시작](../README.md#빠른-시작)을 참고하세요. 소스 상태에서는 Windows `start.cmd`, macOS/Linux `sh start.sh`로 실행할 수도 있습니다.

기본 주소는 `http://127.0.0.1:8768`입니다. Windows `--desktop`은 별도 Edge 앱 창을 사용하고, 다른 환경은 브라우저를 엽니다. 창을 닫아도 서버는 유지되므로 실행 터미널에서 Ctrl+C로 종료합니다. 네이티브 설치 프로그램과 백그라운드 서비스는 제공하지 않습니다.

## 첫 연결

데모는 계정이나 모델 호출 없이 UI를 체험하는 모드입니다. 실제 연결에는 별도 Coral 서버와 로그인한 CLI가 필요합니다. [Coral 설치 가이드](coral-setup.md)에 서버 배포물·호환 범위와 입력값이 있습니다.

1. 사용할 Claude / Codex / Cursor를 선택합니다.
2. Coral에 등록한 관찰자와 에이전트 MCP URL을 입력합니다. 기본 관찰자 `ops`는 실행 에이전트와 다른 신원이어야 합니다.
3. 필요한 프로젝트 경로와 CLI 실행 파일을 지정합니다.
4. 연결 테스트 후 저장하고 **허브 자동 응답**을 켭니다.

에이전트 선택은 기존 Coral 신원과 CLI를 연결하는 과정입니다. 서버 신원 발급·CLI 설치·서비스 로그인은 자동화하지 않습니다. Hermes/OPS는 외부 관찰자·대화 참여자로 사용할 수 있습니다.

자동 응답은 기본적으로 꺼져 있습니다. 켜면 새 멘션 요청이 로그인한 CLI를 호출하고 서비스 사용량이 발생합니다. 같은 Coral 신원에 다른 자동 응답기가 붙어 있다면 중지하세요.

## 연결 URL과 토큰 갱신

개별 URL 대신 저장소 밖 UTF-8 파일을 지정할 수 있습니다.

```text
ops|http://127.0.0.1:5555/<observer-mcp-endpoint>
claude|http://127.0.0.1:5555/<claude-mcp-endpoint>
codex|http://127.0.0.1:5555/<codex-mcp-endpoint>
cursor|http://127.0.0.1:5555/<cursor-mcp-endpoint>
```

형식 예시이므로 서버에서 발급한 실제 URL로 바꿔야 합니다. Hub는 연결할 때 파일을 다시 읽습니다. 서버 재시작 후 파일 갱신과 사라진 세션 재생성은 서버/설치 도구에서 담당하며 Hub가 토큰을 재발급하지는 않습니다.

현재 어댑터는 HTTP MCP initialize, `coral://state` 리소스와 Coral 스레드·메시지 도구를 사용합니다. 다른 서버 버전의 호환성을 보장하지 않습니다.

## 대화와 작업

- **대화:** 첫 요청에 멘션한 에이전트만 참여합니다. 진행 중 추가 메시지는 팀 변경이 아닌 추가 지침입니다. 다른 팀으로 새 요청을 하려면 다른 채널을 사용하세요.
- **독립 투표:** 지문과 선택지를 기준으로 개별 판단하고 마감 후 공개합니다. [투표 안내](voting.md).
- **작업:** 계획·구현·검토 담당자를 지정합니다. 원본과 분리된 사본에서 순차 실행합니다. [작업 안내](pipeline.md).
- **사무실:** 작업 상태를 공간으로 보여주며 추가 모델 호출은 발생하지 않습니다. 캐릭터를 눌러 내용을 확인하거나 대화로 이동합니다.

토론의 합의문은 **이 합의안으로 작업 준비**로 전달합니다. 작업 후 같은 채널의 새 토론에는 최근 종료된 작업 맥락을 고정해 제공합니다. 특정 과거 작업은 **이 작업에 대해 대화하기**를 사용하세요. 진행 중 역할 작업에 보낸 일반 메시지는 기록으로만 남으며 작업 조건을 바꾸지 않습니다.

첫 연결이나 자동 응답 재활성화 시 과거 멘션을 소급 실행하지 않습니다. 자동 응답을 끄면 관찰 모드가 되며 진행 중 협업은 취소됩니다. 실행 중 재시작된 작업은 보류하고 자동 재실행하지 않습니다. 중복을 줄이는 큐·전송 표식은 있지만 분산 환경에서 정확히 한 번 실행을 보장하지는 않습니다.

## 채널과 읽음 표시

채널은 상단 고정 후 최신 대화순으로 표시합니다. 이름 변경·고정·읽음 위치는 브라우저 프로필에 저장되며 다른 참여자에게 적용되지 않습니다. 브라우저 데이터 삭제 시 초기화됩니다.

읽지 않은 메시지에는 첫 방문 시 기존 기록도 포함됩니다. 대화 탭에서 필터 없이 맨 아래까지 읽으면 읽음 처리합니다. 다른 탭이나 숨겨진 창에서는 읽음 처리하지 않습니다.

**채널 닫기**는 영구 삭제가 아닙니다. 닫기 직전 기록을 로컬 DB에 보관하며 **닫힌 채널 표시**로 다시 읽을 수 있습니다. 다시 열기는 지원하지 않습니다. 실행 중 작업은 먼저 완료/취소해야 하고 대기 작업은 닫을 때 취소됩니다. 외부 에이전트는 Hub가 중지시킬 수 없습니다. 다른 클라이언트가 먼저 닫았거나 닫기 직전에 도착한 메시지까지 보관을 보장하지는 않습니다.

## 모델 설정

상단 **모델 설정**에서 에이전트별 다음 호출 모델을 선택하거나 ID를 입력합니다. 빈칸은 CLI 기본값입니다. 실행 중 호출은 유지하며 각 CLI의 전역 모델 설정을 수정하지 않습니다.

목록 새로고침은 설치된 CLI의 메타데이터를 조회합니다. 계정에서 사용할 수 없는 모델은 실제 실행 시 오류가 날 수 있습니다. CLI 출력에 실제 모델 정보가 없으면 추정하지 않고 미확인으로 표시합니다. Auto·별칭은 실제 실행 모델과 다를 수 있습니다.

## 데이터와 실행 범위

| OS | 기본 데이터 폴더 |
| --- | --- |
| Windows | `%LOCALAPPDATA%/AgentHub` |
| macOS | `~/Library/Application Support/AgentHub` |
| Linux | `$XDG_STATE_HOME/agent-hub` 또는 `~/.local/state/agent-hub` |

`AGENT_HUB_HOME` 또는 `--data-dir`로 변경합니다. `workspaces/`는 작업 사본, `runs/`는 실행 로그, `artifacts/`는 결과물입니다. 자동 정리하지 않으므로 용량이 늘어날 수 있습니다. 사본을 삭제하면 후속 대화에서 해당 파일을 직접 확인할 수 없습니다.

설정 파일은 접속 URL을 포함하며 암호화 저장소가 아닙니다. 개인 대화·인증 정보·실행 로그는 Git에 올리지 마세요. 서버는 루프백 전용이며 인터넷에 공개하는 원격 서비스가 아닙니다.

토론·투표는 읽기 전용이며 역할 작업의 구현 단계에서만 쓰기를 허용합니다. CLI 모드와 사본 분리가 모든 도구에 대한 OS 수준의 완전한 격리를 보장하지는 않습니다. 화면의 연결·작업 상태는 이 Hub 기준이며 외부 CLI의 로그인 상태나 외부 작업까지 추적하지 않습니다.
