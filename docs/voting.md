# 독립 비밀 투표

대화 입력창의 **독립 비밀 투표**에서 지문·선택지 2~4개·참여자·마감(5/15/30분)을 지정합니다. 기존 채널 대화는 자동 포함하지 않으므로 판단에 필요한 자료를 지문에 넣으세요. 시작 후 지문, 선택지, 참여자는 고정됩니다. 기존 작성 중인 메시지 초안은 유지합니다.

선택한 에이전트만 새로운 CLI 호출에서 동일한 지문과 선택지를 받습니다. 다른 에이전트의 응답, 이전 대화, 작업 폴더, 0-turn inbox는 제공하지 않습니다. 각자 한 번만 선택과 주장·근거·우려를 제출하며 재토론·자동 재시도는 없습니다. 기권할 수 있습니다. 기본 15분은 CLI 실행 대기도 포함하며 개별 CLI의 기존 10분 실행 제한은 유지됩니다.

전원 처리 완료 또는 마감 때 동시 공개합니다. 미응답·실패·기권을 구분하고, 동률은 공동 최다 득표로 표시합니다. 유효 선택표가 없으면 승자를 만들지 않습니다. 득표는 정답 보장이나 실행 승인이 아닙니다. 취소한 투표는 표를 공개하지 않습니다. 앱 재시작 시 실행 중이던 표는 실패로 처리하고 임의로 재호출하지 않습니다. 아직 시작하지 않은 표는 원래 마감 안에서 진행합니다.

사무실에서 **업무 사무실 / 투표실**을 전환합니다. 업무 사무실은 기존 구조를 유지합니다. 투표실은 공개 전 각자 작업석에 머물고, 공개 후 선택 구역으로 이동합니다. 같은 선택을 한 에이전트끼리 모이며 캐릭터를 누르면 근거를 읽을 수 있습니다. 투표 선택 목록에서 이전 투표도 확인합니다. 접근성 설정의 동작 줄이기를 존중합니다.

한 채널에서는 합의 토론과 투표를 동시에 시작하지 않습니다. 투표 중 보낸 메시지는 대화 기록으로만 남으며 새 작업을 시작하거나 진행 중인 지문을 바꾸지 않습니다. 변경이 필요하면 취소하고 새 투표를 시작하세요. 다른 채널의 작업은 기존 에이전트별 실행 슬롯을 공유하며 계속 처리됩니다. 자동 응답 끄기·연결 설정 변경·채널 닫기는 진행 중 투표를 취소합니다.

## 비밀의 범위

`/api/state`와 `/api/result`는 공개 전 또는 취소된 투표의 개별 선택·주장·근거를 반환하지 않습니다. Coral에는 공개된 최종 집계와 근거 요약만 한 번 전송하며 에이전트 멘션을 붙이지 않습니다. 지문과 투표 원본은 기존 로컬 SQLite/실행 로그에 저장됩니다. 데모는 명시적인 가짜 예시이며 모델을 호출하지 않습니다.

이는 앱 수준의 독립 판단·동시 공개 방식입니다. 암호화된 선거 시스템이나 운영체제 수준의 에이전트 격리는 아닙니다. 사용자의 로컬 파일·CLI 기본 설정에 접근할 수 있는 관리자까지 차단하지 않습니다. 에이전트에는 도구·파일·외부 서비스 사용 금지를 지시하며 다른 표를 전달하지 않지만, 각 CLI의 모든 사용자 설정을 허브가 통제하지는 않습니다. 같은 모델 계열의 오류 상관관계도 남습니다.
